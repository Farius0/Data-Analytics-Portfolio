
# Tableau -- Analytics Dashboards Portfolio

This repository contains **interactive Tableau dashboards** designed to demonstrate business-oriented analytics, KPI engineering, and decision-support reporting using structured datasets.

The objective is to showcase practical dashboard development workflows across multiple analytical contexts:

- workforce analytics
- sales performance monitoring
- demographic segmentation
- compensation analysis
- geographic distribution insights

These dashboards simulate real-world analytics scenarios typically encountered in business intelligence environments.


---

# Projects

## 1️⃣ HR Analytics Dashboard

An interactive workforce analytics solution designed to explore organizational structure, demographic composition, and compensation patterns.

### Features

- workforce structure overview
- department distribution analysis
- demographic segmentation
- education vs performance comparison
- salary distribution analysis
- tenure-based workforce exploration
- employee-level filtering interface

### Dashboard Preview

![HR Dashboard](HR%20Dashboard/dashboards/hr_dashboard.gif)

Provides both:

- executive-level workforce insights
- operational employee-level exploration

## 2️⃣ Sales Performance Dashboard

A business performance monitoring solution designed to analyze revenue evolution, product contribution, customer segmentation, and geographic sales distribution.

### Features

- KPI monitoring (sales, profit, quantity)
- product category performance
- customer segmentation analysis
- regional performance comparison
- trend evolution analysis
- top-N ranking analytics

### Dashboard Preview

![Sales Dashboard](Sales%20Dashboard/dashboards/sales_dashboard.gif)

Supports multi-dimensional commercial performance exploration.
