# Qlik Sense -- Sales Analytics Dashboards

This repository contains **interactive sales dashboards built with Qlik Sense**, demonstrating both:

- a complete BI pipeline project
- a lightweight dashboard analytics project

The objective is to showcase **data modeling, KPI engineering, and interactive business analytics** using Qlik Sense.

---

# Projects

## 1️⃣ Sales Data Mart Dashboard

A complete BI project including:

- data integration
- dimensional modeling
- fact table construction
- interactive dashboards

### Features

- customer analytics
- product performance
- sales trend monitoring
- geographic sales analysis
- employee sales performance

### Architecture

```
Raw Data
   ↓
Dimensions
   ↓
Fact Table
   ↓
Qlik Sense Dashboard
```
